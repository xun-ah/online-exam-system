# 填空题多空设置指南

## 功能说明

系统现已支持**多空填空题**的自动评分功能。教师可以设置包含多个空位的填空题，系统会根据学生答对的数量按比例给分。

---

## 一、题目内容设置

### 规则
使用**连续下划线**（至少2个）表示空位，例如：
- `__` （2个下划线）
- `____` （4个下划线）
- `______` （6个下划线）

### 示例

#### 单空题
```
级数 Σ_{n=1}^∞ 1/n^p 当 p______ 时收敛。
```

#### 多空题（2个空）
```
级数 Σ_{n=1}^∞ 1/n^p 当 p______ 时收敛，当 p______ 时发散。
```

#### 多空题（3个空）
```
函数 f(x) 在 x=______ 处取得极大值，在 x=______ 处取得极小值，拐点为 x=______。
```

---

## 二、答案设置

### 规则
使用 **竖线 `|`** 分隔多个空的答案，答案顺序必须与题目中的空位顺序一致。

### 示例

#### 单空题
```
答案：>1
```

#### 多空题（2个空）
```
答案：>1|≤1
```
说明：
- 第1空答案：`>1`
- 第2空答案：`≤1`

#### 多空题（3个空）
```
答案：1|-1|0
```
说明：
- 第1空答案：`1`
- 第2空答案：`-1`
- 第3空答案：`0`

---

## 三、评分规则

### 1. 完全匹配模式
如果设置答案时不区分多空（没有使用 `|`），则必须完全匹配才能得分。

### 2. 多空按比例给分（推荐）
当答案使用 `|` 分隔时，系统会根据答对的数量按比例给分。

**示例：**
- 题目有3个空，总分5分
- 正确答案：`A|B|C`
- 学生答案：`A|B|D`

**评分结果：**
- 答对数量：2个（A和B）
- 得分：5 × (2/3) = 3.3分

---

## 四、注意事项

### ✅ 正确做法
1. 使用连续下划线（至少2个）标记空位
2. 答案使用 `|` 分隔，数量与空位数量一致
3. 答案顺序与题目空位顺序对应

###  错误做法
1. 使用单个下划线 `_`（不会被识别）
2. 答案数量与空位数量不一致
3. 答案中使用 `|` 但没有多空

## 六、学生答题界面

学生看到的界面：
1. 题目中的下划线会显示为**蓝色占位符**
2. 下方显示多个输入框，标注"第1空"、"第2空"等
3. 学生依次填写每个空的答案
4. 系统自动将答案合并为 `答案1|答案2|答案3` 格式提交

## 七、技术实现

### 前端识别逻辑
```javascript
// 检测空位数量（匹配连续2个以上的下划线）
const matches = question.content.match(/_{2,}/g)
const blankCount = matches ? matches.length : 0
```

### 后端评分逻辑
```java
// 按 | 分隔答案
String[] correctAnswers = correctAnswer.split("\\|");
String[] studentAnswers = studentAnswer.split("\\|");

// 逐个比较，统计答对数量
int correctCount = 0;
for (int i = 0; i < minLength; i++) {
    if (correctAnswers[i].equalsIgnoreCase(studentAnswers[i])) {
        correctCount++;
    }
}

// 按比例给分
double ratio = (double) correctCount / correctAnswers.length;
score = fullScore × ratio;
```

## 常见问题

### Q1: 如果答案中包含 `|` 字符怎么办？
**A:** 建议使用其他符号或转义，目前 `|` 作为分隔符保留。

### Q2: 答案是否需要精确匹配？
**A:** 系统会忽略大小写和首尾空格，但内容必须一致。

### Q3: 可以设置部分空不给分吗？
**A:** 目前所有空位平均分配分数，暂不支持权重设置。
